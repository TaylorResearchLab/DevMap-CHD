# DevMap-CHD 2026.09.08

This directory contains release 2026.09.08.

The release contains 662 genes, 14 membership sets from 6 source groups, and 2,177 records linking genes to source sets. HGNC and Ensembl identifiers are available for all 662 genes.

The files are

- `genes.tsv`
- `gene_source_membership.tsv`
- `source_membership_matrix.tsv`
- `source_manifest.tsv`
- `release_metadata.json`
- `SHA256SUMS.txt`

Source definitions and citations are provided in `source_manifest.tsv`.
